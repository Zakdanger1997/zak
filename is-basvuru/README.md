# İş Başvuru Asistanı (n8n + Telegram + AI)

Telegram'dan gönderdiğiniz mail listesini AI ile analiz edip, her firmaya özel iş başvuru maili hazırlayan ve **sadece sizin onayınızla** CV ekli mail gönderen n8n workflow'u.

- 🔍 Mail adresinden firmayı AI tespit eder
- ✍️ Firmaya özel başvuru maili yazar
- ✅ Telegram'dan onay butonuyla sorar — onay vermezseniz asla göndermez
- 📋 Gönderilenleri Google Sheets'e kaydeder
- 🚫 Aynı firmaya ikinci kez mail atmaz

| Dosya | Açıklama |
|---|---|
| [`workflow/is_basvuru_asistani.json`](workflow/is_basvuru_asistani.json) | n8n'e import edilecek workflow dosyası |
| [`KURULUM_REHBERI.md`](KURULUM_REHBERI.md) | Sıfırdan adım adım kurulum ve kullanım rehberi (Türkçe) |
