# 🪖 جيش وكلاء المحتوى (Content Army) — بقيادة فيبل 5

مشروع مستوحى من فكرة "جيش الوكلاء تحت قيادة فيبل": بدلاً من أن يكتب نموذج واحد كل شيء، يقوم **فيبل 5 (Claude Fable 5)** بدور القائد ويوزّع العمل على **جيش من الوكلاء المتخصصين** يعملون بالتوازي داخل Claude Code، ثم يراجع بعضهم عمل بعض قبل تسليم النتيجة النهائية.

## 🎯 ماذا يفعل؟

تعطيه **موضوعاً تسويقياً واحداً**، فيعيد لك **حزمة محتوى كاملة وجاهزة للنشر**:

- تقارير بحث حقيقية من الإنترنت (ترندات، جمهور، منافسون، هاشتاغات)
- استراتيجية محتوى وركائز أساسية
- أفكار محتوى مبنية على فجوات المنافسين
- لكل فكرة: منشور **لينكدإن** + سلسلة تغريدات **X** + سكربت **ريلز/تيك توك**
- كل قطعة محتوى مرّت على **مراجع عدائي** قيّمها وحسّنها قبل التسليم

## ⚙️ كيف يعمل الجيش؟ (4 مراحل)

```
المرحلة 1: البحث (4 وكلاء بالتوازي)
   ├── وكيل الترندات      → ما الذي ينجح الآن؟
   ├── وكيل الجمهور       → من نخاطب وما آلامه؟
   ├── وكيل المنافسين     → ما الفجوات المتاحة؟
   └── وكيل الهاشتاغات    → بأي كلمات نُكتشف؟
              │ (تُجمع النتائج الأربع معاً)
              ▼
المرحلة 2: الاستراتيجية (وكيل واحد خبير)
   يقرأ التقارير الأربعة → خطة + ركائز + أفكار محتوى
              │
              ▼
المرحلة 3: الإنتاج (كاتب لكل فكرة × كل منصة، بالتوازي)
   فكرة 1 → كاتب لينكدإن + كاتب X + كاتب ريلز
   فكرة 2 → كاتب لينكدإن + كاتب X + كاتب ريلز
   فكرة 3 → كاتب لينكدإن + كاتب X + كاتب ريلز
              │ (كل فكرة تتقدم للمراجعة فور جاهزيتها — لا انتظار)
              ▼
المرحلة 4: المراجعة العدائية (مراجع لكل قطعة)
   يقيّم من 10، يكتشف الحشو والعبارات المستهلكة،
   ويعيد كتابة النسخة النهائية المحسّنة
```

المجموع: **حوالي 23 وكيلاً** لكل تشغيلة (4 بحث + 1 استراتيجية + 9 كتّاب + 9 مراجعين).

## 🚀 كيف تشغّله؟

1. افتح جلسة Claude Code على هذا المستودع (من claude.ai/code أو التطبيق)
2. اكتب طلباً مثل:

   > شغّل workflow ملف `content-army/workflow/content_army.workflow.js` عن موضوع: التسويق لمتجر قهوة مختصة في إسطنبول، الجمهور: عشاق القهوة 20-35 سنة، الهدف: زيادة الزيارات للمتجر

3. تابع تقدم الوكلاء مباشرة عبر الأمر `/workflows`
4. عند الانتهاء ستجد النتائج محفوظة في مجلد `output/`

### المدخلات التي يقبلها (args)

| الحقل | الوصف | مثال |
|---|---|---|
| `topic` | الموضوع/المشروع | "متجر عطور إلكتروني" |
| `audience` | الجمهور المستهدف | "نساء 25-40 في الخليج" |
| `goal` | الهدف التسويقي | "زيادة المبيعات" |
| `tone` | نبرة الكتابة | "فاخرة وأنيقة" |
| `language` | لغة المحتوى | "العربية" |
| `ideasCount` | عدد الأفكار (1-5) | 3 |

## 📁 الملفات

| الملف | الوصف |
|---|---|
| `workflow/content_army.workflow.js` | سكربت الجيش (يُنفذ عبر أداة Workflow في Claude Code) |
| `output/` | نتائج التشغيلات: الاستراتيجية + المحتوى الجاهز للنشر |

## 💡 لماذا هذا أفضل من طلب واحد لنموذج واحد؟

- **تخصص**: كل وكيل يركز على مهمة واحدة صغيرة فيتقنها
- **توازٍ**: 9 كتّاب يعملون في نفس اللحظة بدل الواحد تلو الآخر
- **جودة**: المراجع العدائي يمسك الحشو والضعف قبل أن يصلك
- **بحث حقيقي**: وكلاء البحث يستخدمون الإنترنت فعلياً، لا الذاكرة فقط
