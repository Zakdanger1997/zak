How this is calculated
Rope pull: F = (Q · g) / z Drum speed: n_drum = (v_hook · z) / (π · D_drum) Drum torque: T_drum = (Q · g · r) / z, r = D_drum / 2 Motor power: P = (Q · g · v_hook) / (60,000 · η) Motor torque: T_motor = 9550 · P / n_motor Gearbox ratio: i = n_motor / n_drum Q = load (kg) g = 9.81 m/s² z = number of falls v_hook = hoisting (hook) speed (m/min) D_drum = drum diameter (m) r = drum radius (m) = D_drum / 2 (e.g. r = (d[mm] / 2) · 0.001) η = overall mechanism efficiency (reeving + gearbox + bearings) — applied to motor power sizing only n_motor = motor speed (rpm) P = motor power (kW)

Drum diameter is taken as the rope pitch diameter (drum barrel to rope centerline); for a precise design add the rope diameter to the barrel diameter before entering it here. "Required motor power" is rounded up to the nearest standard IEC motor frame size as a suggestion — always re-check against the manufacturer's duty/class rating (FEM/ISO 4301) and starting torque needs.

Engineering note: This tool gives a preliminary estimate for hoist drive sizing only. It does not account for duty class / load spectrum (FEM 9.511, ISO 4301), acceleration torque, starting duty cycle, motor thermal class, or safety factors required by crane design codes. Final motor and gearbox selection must be verified by a qualified engineer against the applicable standards.
