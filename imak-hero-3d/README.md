# i.Mak — ray-traced "golden hour" hero images

Photoreal product hero images for the milling / grain story (Millers' Guide article), built
**from scratch as a real 3D scene** and ray-traced — no AI image generator, no stock-photo
cut-and-paste. The product is i.Mak's own render; everything around it is modelled and lit.

## Deliverables (`out/`)
| File | Use |
|------|-----|
| `irnx_hero_clean_16x9.jpg` | Clean hero, no text — article / web / print |
| `irnx_ad_16x9.jpg` | Hero + logo + headline — web banner, LinkedIn link post |
| `irnx_ad_1x1_linkedin.jpg` | Square ad for LinkedIn / Instagram |
| `irnx_ad_4x5_linkedin_feed.jpg` | Portrait ad (dedicated camera) — best feed format |
| `irnx_hero_clean_4x5.jpg`, `irnx_hero_clean_1x1.jpg` | Clean crops for your own layouts |
| `irk_*.jpg` | Same scene with the IRK helical-bevel geared motor |

## What is in the scene
- **Product**: the real IRNX 06 render (1181 px, extracted from the public IRNX 2024 catalogue PDF)
  and the supplied IRK render. Baked studio floor shadows were removed; a faint warm rim was added.
- **Wheat**: procedural plants — stem, rachis, ~40 kernels and awns per ear — ~20,000 instances,
  plus cut sheaves lying on the slab and blurred foreground ears.
- **Grain**: ~3,000 individual kernels piled and scattered on the slab.
- **Podium**: polished dark marble slab (true ray-traced reflection of the product) on rough rock.
- **Grain terminal**: two receding rows of corrugated silos with galleries and a bucket-elevator leg.
- **Light**: a real captured sunset sky (Poly Haven HDRI *The Sky Is On Fire*, CC0) + a low warm sun
  for rim light + one soft fill; depth of field from a 60 mm f/2.8 camera (90 mm for the portrait).

## Why it looks the way it does (research behind the choices)
- LinkedIn B2B creative guidance: single images remain the workhorse; **high contrast, one large
  text element, minimal on-image text**; 1200×628 / 1200×1200, and small text is risky on mobile.
  → one short headline, big product, three formats.
- Product-photo craft: **backlight for separation**, **complementary colour contrast** (brand red
  against amber/teal), ~45° hero angle. → backlit golden hour, sun on the product's shoulder.
- Grain-handling drives: shaft-mounted and helical-bevel units drive **bucket elevators, conveyors
  and mixers** — and i.Mak's own IRNX catalogue already uses silos / wheat / grain imagery.

## Pipeline
```bash
pip install bpy numpy pillow scipy          # Blender as a Python module (Cycles renderer)
./fetch_assets.sh                           # downloads the CC0 sky HDRI into hdri/
python scene.py --product irnx --res 2560x1440 --samples 160 --out out/final_irnx
python post.py out/final_irnx out/final_irnx_hero.png          # true-colour product, bloom, grade
python overlay.py out/final_irnx_hero.png out irnx             # clean + ad versions, crops
# portrait (LinkedIn feed):
python scene.py --product irnx --res 1440x1800 --samples 128 --fit HORIZONTAL --lens 90 --aim_z 1.62 --out out/final_irnx_port
python post.py out/final_irnx_port out/final_irnx_port_hero.png --sun 0.741,0.466
python overlay.py out/final_irnx_port_hero.png out irnx
```
`scene.py` renders two passes: **A** the beauty render, **B** the product alone in exact brand
colour with its coverage matte; `post.py` blends B over A so the i.Mak red is not shifted by the
film tone curve. Quick previews: `--res 640x360 --samples 24` (~20 s on 4 CPU cores).

Useful knobs: `--product irnx|irk`, `--hdri <file>`, `--sun_az`, `--sun_drop` (sky framing),
`--sun` (rim-light strength), `--exposure`, `--fstop`, `--lens`, `--density` (wheat count).
Headline / tagline text lives at the top of `overlay.py`.
